11.Methodology & limitations

How this corpus was assembled

  1. Scraped the official OMR catalog (library.ldraw.org/omr/sets) — 1,470 sets in total.
  2. Selected sets across 8 cohorts: 80s/90s, kids, classic (Plan C), classic gaps, modern, technic, specialty, licensed.
  3. Downloaded each set's MPD via https://library.ldraw.org/library/omr/{SET}-{Q}.mpd.
  4. Parsed all MPDs with analysis/batch_parse3.py (handles CRLF, sub_model suffix, embedded custom parts).
  5. Aggregated stats per cohort with the same script. Output: analysis/cross_corpus3_stats.json.
  6. Dispatched 4 parallel subagents for chaining / themes / cohorts / generator analysis.
  7. Derived 23 conventions: 7 confirmed, 8 weakened, 2 refuted, 6 new.

Limitations

  • OMR has ~1,470 sets; we sampled 1,438 (97.8%). The remaining 32 are mostly recent or low-priority.
  • OMR doesn't include every LEGO set (Ninjago, many Star Wars post-2010, several Icons).
  • The Pirates theme is dominated by 6286 Skull's Eye Schooner (2,834 pieces) — 86% of the theme.
  • Custom parts and textures are not deeply analyzed.
  • Sub-build hierarchy within MPDs is not studied.
  • No comparison with MOCs (non-OMR community models).
